## 1. Введение

Метод простых итераций является классическим итерационным методом решения систем линейных алгебраических уравнений (СЛАУ). В отличие от прямых методов (например, метода Гаусса), итерационные методы позволяют получить приближенное решение с заданной точностью и хорошо подходят для распараллеливания, особенно для больших разреженных матриц.

Целью данной работы является реализация параллельного варианта метода простых итераций с использованием технологии MPI (Message Passing Interface) и сравнение его производительности с последовательной версией.

## 2. Постановка задачи

**Задача:** Решить систему линейных уравнений **Ax = b** методом простых итераций, где:
- **A** — квадратная матрица размером n×n (в данной реализации используется единичная матрица I)
- **b** — вектор правых частей размером n (заполнен единицами: b = [1, 1, ..., 1]ᵀ)
- **x** — искомый вектор решения размером n

**Входные данные:**
- Целое число n > 0 — размерность системы

**Выходные данные:**
- Целое число — округленная сумма компонент решения ∑xᵢ

**Ограничения:**
- n > 0
- Максимальное число итераций: 1000
- Точность сходимости: epsilon = 10⁻⁶
- Параметр релаксации: τ = 0.5

## 3. Описание базового алгоритма (последовательная версия)

Метод простых итераций основан на итерационной схеме:

**x^(k+1) = x^(k) - τ(Ax^(k) - b)**

где:
- **x^(k)** — приближение решения на k-й итерации
- **τ** — параметр релаксации (шаг итерации)
- **A** — матрица системы
- **b** — вектор правых частей

**Алгоритм:**

1. **Инициализация:**
   - Начальное приближение: x^(0) = [0, 0, ..., 0]ᵀ
   - Инициализация матрицы A как единичной: A[i][i] = 1
   - Вектор правых частей: b = [1, 1, ..., 1]ᵀ

2. **Итерационный процесс** (для k = 0, 1, 2, ...):
   - Для каждой компоненты i:
     - Вычислить (Ax)ᵢ = Σⱼ A[i][j] * x^(k)[j]
     - Обновить: x^(k+1)[i] = x^(k)[i] - τ * ((Ax)ᵢ - b[i])
   - Вычислить норму изменения: ||x^(k+1) - x^(k)||₂
   - Если ||x^(k+1) - x^(k)||₂ < ε, завершить
   - Если k ≥ max_iterations, завершить

3. **Постобработка:**
   - Вычислить сумму компонент решения: result = Σᵢ x[i]
   - Округлить до целого числа

**Сложность:** O(n² × iter), где iter — количество итераций до сходимости.

## 4. Схема распараллеливания (MPI)

Распараллеливание основано на декомпозиции по строкам матрицы A между MPI-процессами.

### 4.1 Распределение данных

**Топология:** Master-Worker с коллективными операциями

**Распределение строк:** Каждому процессу с рангом `rank` (из `size` процессов) назначается блок строк:
- Количество строк на процесс: `rows_per_proc = n / size`
- Остаток: `remainder = n % size`
- Процессы с `rank < remainder` получают на одну строку больше
- Начальная строка процесса: `start_row = rank * rows_per_proc + min(rank, remainder)`
- Количество строк процесса: `local_rows = rows_per_proc + (rank < remainder ? 1 : 0)`

**Пример распределения** для n=10, size=3:
- Процесс 0: строки 0-3 (4 строки)
- Процесс 1: строки 4-7 (4 строки)
- Процесс 2: строки 8-9 (2 строки)

### 4.2 Схема коммуникации

На каждой итерации:

1. **Локальные вычисления:** Каждый процесс вычисляет произведение своих строк матрицы A на текущий вектор x:
   ```
   для i от 0 до local_rows:
       global_i = start_row + i
       local_ax[i] = Σⱼ A[global_i][j] * x[j]
   ```

2. **Коллективная операция MPI_Allgatherv:**
   - Собирает локальные результаты `local_ax` от всех процессов в глобальный вектор `ax_global`
   - Все процессы получают полный вектор `ax_global`

3. **Обновление вектора x:** Все процессы одинаково обновляют весь вектор x:
   ```
   для i от 0 до n:
       x_new[i] = x[i] - τ * (ax_global[i] - b[i])
   ```

4. **Проверка сходимости:** Вычисление нормы ||x_new - x|| выполняется на всех процессах

5. **Финализация:**
   - Процесс 0 вычисляет итоговый результат
   - `MPI_Bcast` распространяет результат на все процессы

### 4.3 Диаграмма коммуникации

```
Итерация k:
┌─────────┐       ┌─────────┐       ┌─────────┐
│Process 0│       │Process 1│       │Process 2│
└────┬────┘       └────┬────┘       └────┬────┘
     │                 │                 │
     ├─ Compute local_ax[0:3]            │
     │                 ├─ Compute local_ax[4:7]
     │                 │                 ├─ Compute local_ax[8:9]
     │                 │                 │
     ├────────────── MPI_Allgatherv ─────┤
     │◄──────────────────┬───────────────►│
     │                   │                │
     ├─ Update x[0:n-1] ─┼─ Update x[0:n-1] ─┼─ Update x[0:n-1]
     │                   │                │
     ├─ Check convergence                 │
     │                   │                │
```

## Приложение

### Фрагмент кода: основной вычислительный цикл (MPI)

```cpp
for (int iteration = 0; iteration < max_iterations; iteration++) {
  // Локальное вычисление произведения матрицы на вектор
  for (int i = 0; i < local_rows; i++) {
    int global_i = start_row + i;
    double ax_i = 0.0;
    for (int j = 0; j < n; j++) {
      ax_i += a[global_i][j] * x[j];
    }
    local_ax[i] = ax_i;
  }

  // Сбор результатов от всех процессов
  std::vector<double> ax_global(n, 0.0);
  MPI_Allgatherv(local_ax.data(), local_rows, MPI_DOUBLE, 
                 ax_global.data(), recvcounts.data(), displs.data(),
                 MPI_DOUBLE, MPI_COMM_WORLD);

  // Обновление решения
  for (int i = 0; i < n; i++) {
    x_new[i] = x[i] - (tau * (ax_global[i] - b[i]));
  }

  // Проверка сходимости
  double diff = ComputeVectorNorm(x_new, x, n);
  x = x_new;

  if (diff < epsilon) {
    break;  // Достигнута требуемая точность
  }
}
```
